## Platform Used

## Project Description

Kigali Eats Fresh Store is an online food store developed using Wix. The website allows customers to browse food products, view prices, learn about the business, and interact with a shopping cart.


## Features Implemented

- Homepage with welcome message
- Product page with 10 products
- About page
- Contact page
- Shopping cart functionality
- Mobile-friendly design
